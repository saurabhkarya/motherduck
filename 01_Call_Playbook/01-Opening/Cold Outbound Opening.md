# Cold Outbound Opening
**For cold calls with no prior engagement**

---

## The Goal
Survive the pickup. Go undetected. Sound like a person, not a vendor.

---

## Opening Script
```
Hey [Name], this is Arya from MotherDuck - did I catch you at an okay time?

[Wait for response]

I'll be quick - I noticed you [downloaded our ebook / tried DuckDB / etc].
I'd love to learn a little about what you were exploring or what's on your mind.
```

---

## If They Ask "What is MotherDuck?"

**The Elevator Pitch (memorize this):**
```
"MotherDuck is a cloud data warehouse built on top of DuckDB.

We have a very unique architecture which offers people a lot of
performance gains and cost controls compared to traditional alternatives -
and opens up some other use cases too."

[STOP. Let them ask the next question.]
```

**Key elements:**
- Cloud data warehouse (NOT "storage layer")
- Built on DuckDB
- Unique architecture
- Performance + cost + "other use cases" (leave vague)

---

## If They Mention They Use DuckDB
```
"Oh cool, great - so you're familiar with DuckDB.
What do you think of it?"

[They say it's great]

"Yeah, so MotherDuck is actually a cloud data warehouse built on top of it.
We offer performance gains and cost controls compared to traditional
alternatives - and open up some other use cases.

What brought you to check it out originally?"
```

---

## If They Mention Snowflake/BigQuery/etc.
```
"Cool - do you guys compete with Snowflake?"

"Yeah, actually we do. A lot of customers use MotherDuck either to
replace Snowflake holistically, or use us as their gold tier or
serving layer - or even to power external-facing analytics or
MCP-style use cases.

I mean, is Snowflake powering all of that today? Do you do any
external-facing stuff?"
```

**Don't shy away from competition.** But redirect to where we have home field advantage.

---

## Golden Rules for Opening

1. **Go undetected** - Relaxed, casual, not salesy
2. **Don't pitch until you know their situation** - You'll box yourself in
3. **Leave things open-ended** - Invite them to ask questions
4. **Never ask yes/no questions** - Kills the conversation

## If They Push Back
| They Say | You Say |
|----------|---------|
| "I'm busy" | "That's fair - better time this week?" |
| "Not looking right now" | "Totally get it. What would change for this to be worth revisiting?" |
| "Send me info" | "What specifically - pricing, technical docs? I'll send and follow up." |
| "We already use Snowflake" | "Cool - tell me a bit about that. What are you using it for today?" |
