# Exploring Options
**When they say: "We're just exploring" / "Seeing what's out there"**

---

## Dig Into the Trigger
```
"What prompted you to start exploring?"

Is there a specific problem you're trying to solve, or more of a
general 'let's see what's out there'?
```

---

## Listen for the Real Pain
After they answer, listen for:
- Cost concerns → [[03-Pain-Points/Cost Pain]]
- Speed issues → [[03-Pain-Points/Speed Pain]]
- Complexity → [[03-Pain-Points/Complexity Pain]]

---

## If Still Vague
```
"Got it. So [restate trigger] - is that a big deal or a smaller annoyance?"
```

Then:
```
"That's exactly what we help with. Let me get you in front of
someone who can show you specifically how."
```

---

## If Comparing Competitors
Ask:
```
"Have you looked at alternatives yet, or is this your first conversation?"
```

Then go to:
→ [[04-Deep-Discovery/Looking at alternatives]]
→ [[06-Competitors/]] (based on which competitor)
