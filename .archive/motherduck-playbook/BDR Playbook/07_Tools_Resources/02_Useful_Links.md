## Quick Reference Cards

### Elevator Pitch
> "MotherDuck is a serverless cloud data warehouse built on DuckDB. 
> It's 70% cheaper than Snowflake, requires zero infrastructure, 
> and lets you develop locally with instant feedback."

### Three Key Differentiators
1. **Serverless** - No clusters, no tuning
2. **Hybrid** - Local + cloud together
3. **Cost** - 70% cheaper, pay-per-query

### Common Use Cases
1. Internal BI & analytics
2. Customer-facing analytics
3. Data exploration & ad-hoc queries
4. Lightweight ETL/ELT

### Target Personas
1. Data Engineers
2. Analytics Engineers
3. Technical Founders/CTOs
4. VP Data / Head of Data
