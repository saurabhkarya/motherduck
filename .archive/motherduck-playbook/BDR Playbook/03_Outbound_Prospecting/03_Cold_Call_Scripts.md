# Cold Call Scripts

Phone calls cut through inbox noise. Here are scripts and techniques for effective cold calling.

---

## The Opening: First 30 Seconds

Your opening determines if you get 30 more seconds or a hangup.

### Framework
```
1. Introduce yourself quickly
2. Give a pattern interrupt (unexpected statement)
3. Ask for permission to continue
```

### Script: The Pattern Interrupt
```
"Hi [First Name], this is [Your Name] from MotherDuck. 
Did I catch you at an okay time?"

[Wait for response]

"Great. I'll be quick—I'm not sure we're a fit, but I noticed 
[Company] is [growing/hiring data engineers/etc], and I wanted 
to see if your data infrastructure is keeping up with that growth?"
```

### Script: The Direct Approach
```
"Hi [First Name], this is [Your Name] from MotherDuck. 
We help data teams analyze data faster and cheaper than 
Snowflake—about 70% cheaper actually. 

Is that something worth a quick conversation?"
```

### Script: The Reference Drop
```
"Hi [First Name], this is [Your Name] from MotherDuck. 
We recently helped [Similar Company] cut their warehouse 
costs by 70% while speeding up their queries.

I noticed [Company] has a similar setup—mind if I ask 
what you're using for your data warehouse today?"
```

---

## Handling Initial Responses

### "I'm busy right now"
```
"Totally understand. When's a better time for a quick 5-minute call? 
I'm flexible."
```

### "What is this about?"
```
"We're a serverless data warehouse built on DuckDB. Companies 
like yours use us to analyze data faster and cut costs by 70% 
vs. Snowflake. Does that sound relevant?"
```

### "We're not interested"
```
"Fair enough. Mind if I ask what you're currently using? 
Just want to make sure I'm not calling companies that 
wouldn't benefit."
```

### "Send me an email"
```
"Happy to! What specifically would you want me to include—
are you interested in the cost savings or the performance side?"
```

## Discovery Mini-Script

If you get past the opener, move to discovery:

```
"Great. Quick question—what are you using for your 
data warehouse today?"

[Listen]

"And how's that working for you? Any frustrations?"

[Listen]

"Got it. What would it mean for your team if you could 
[solve that pain point]?"

[Listen]

"That's exactly what MotherDuck helps with. Would it make 
sense to set up a proper demo with one of our engineers?"
```

## Voicemail Scripts

Most calls go to voicemail. Make it count.

### Voicemail 1: The Value Prop
```
"Hi [First Name], [Your Name] from MotherDuck. 

We help data teams analyze data 70% cheaper than Snowflake 
with zero infrastructure to manage. 

I noticed [Company] is [hiring data engineers/growing/etc] 
and wanted to see if we could help.

Give me a call at [number] or I'll try you again [day]. 
Thanks!"
```

### Voicemail 2: The Follow-up
```
"Hi [First Name], [Your Name] again from MotherDuck. 

Just following up on my earlier call. If Snowflake costs 
or data infrastructure complexity is on your radar, 
I'd love to chat.

You can reach me at [number]. Thanks!"
```

### Voicemail 3: The Breakup
```
"Hi [First Name], [Your Name] from MotherDuck. 

This is my last voicemail—I don't want to be a pest. 

If data infrastructure becomes a priority, you know where 
to find me. Take care!"
```

## Objection Handling on Calls

### "We already use Snowflake"
```
"A lot of our customers did too. They switched because of 
cost and complexity. Mind if I ask—are you happy with what 
you're paying?"
```

### "We're too small"
```
"Actually, that's who we're built for. MotherDuck is 
serverless—no infrastructure to manage. Teams your size 
are our sweet spot. Can I ask what you're using today?"
```

### "We don't have budget"
```
"Understood. Our free tier has 10GB and 10 compute hours—
plenty to test. Would that be worth exploring?"
```

### "I'm not the right person"
```
"No problem. Who should I be talking to about your 
data infrastructure? I just want to make sure I'm 
reaching the right folks."
```

### "We're in a contract"
```
"Makes sense. When does that come up for renewal? 
I'd love to connect before then so you have options."
```

## Call Cadence

### Recommended Sequence
| Touch | Timing | Action |
|-------|--------|--------|
| 1 | Day 1 | Call + Voicemail |
| 2 | Day 2 | Email |
| 3 | Day 4 | Call (no voicemail) |
| 4 | Day 5 | LinkedIn connect |
| 5 | Day 8 | Call + Voicemail |
| 6 | Day 10 | Email |
| 7 | Day 14 | Final call + Voicemail |
| 8 | Day 15 | Breakup email |

### Best Times to Call
- **Best**: Tuesday-Thursday, 8-9 AM or 4-6 PM local time
- **Good**: Monday PM, Friday AM
- **Avoid**: Monday AM (meetings), Friday PM (checked out)

---

## Call Preparation Checklist

Before each call:

- [ ] Know their name and company
- [ ] Check LinkedIn for recent activity
- [ ] Know their current tech stack (if available)
- [ ] Have a trigger event ready (funding, hiring, etc.)
- [ ] Know which persona they are
- [ ] Have your CRM open to log notes

---

## Mindset Tips

1. **Rejection is data**: Every "no" teaches you something
2. **You're helping**: You're offering a solution, not bothering
3. **Smile while dialing**: It comes through in your voice
4. **Stand up**: Better energy, better calls
5. **Celebrate small wins**: Got a callback? That's a win.
