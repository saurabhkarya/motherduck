## Days 2-3: Data Warehousing 101

**Goal**: Understand the data landscape and basic terminology.

### Why This Matters

To be credible sellers we need to know our history. Having the basics of data warehousing, its evolution, and the different technologies in play are key to building trust with prospects.

This is an audience which is typically avoidant of sellers, thinking of us as surface level, superficial, pushy, annoying, and generally unhelpful.

We need to challenge that assumption. The only way to do that is to show up knowing our stuff and having an informed perspective.

## Key Terms to Know by End of Week 1

| Term | Definition |
|------|------------|
| **OLTP** | Online Transaction Processing - optimized for writes/transactions |
| **OLAP** | Online Analytical Processing - optimized for complex queries |
| **ETL** | Extract, Transform, Load - transform before loading |
| **ELT** | Extract, Load, Transform - transform after loading |
| **Data Lake** | Raw data storage in native format |
| **Data Warehouse** | Structured, processed data for analytics |
| **Columnar Storage** | Data stored by columns for faster analytics |
| **On-Prem** | Infrastructure hosted in company's own data centers |
