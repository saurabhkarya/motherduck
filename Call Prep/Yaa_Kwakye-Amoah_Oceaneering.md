```
sub-second dashboards.

Would it be worth exploring how they work together?"
```

### "We have a traditional data warehouse"
```
YOU: "Got it. What are you using—Snowflake? Teradata?

[Listen]

A lot of teams keep their warehouse for heavy workloads
but use MotherDuck for fast ad-hoc analytics and
developer use cases. It's 70% cheaper and way simpler
for those secondary workloads."
```

### "Oceaneering has preferred vendors"
```
YOU: "Understood—enterprise procurement has constraints.

Even within those constraints, there's usually room for
best-of-breed tools for specific use cases. Would it be
worth a pilot on a non-critical workload to see if
there's value?"
```

```
YOU: "Totally reasonable. Our free tier has 10GB storage
and 10 compute hours—enough to run a real proof of concept.

Would it help to try it on a specific Oceaneering dataset
and see the performance yourself?"
```
