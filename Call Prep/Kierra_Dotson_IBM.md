## Key Talking Points for Kierra

### 1. MCP Server + AgentOps Alignment
```
"Your AgentOps framework is exactly why we built our MCP
server. In the OPERATE and MONITOR phases, agents need
reliable data access.

Our MCP server lets AI assistants like Claude query
MotherDuck directly—no middleware, no custom integrations.
It's native agent-to-database communication."
```

### 2. POC Speed (for IBM work)
```
"For POCs, speed matters. MotherDuck spins up in seconds—
no cluster provisioning, no warehouse sizing. You can
demo to a client with their actual data running sub-second
queries without any infrastructure setup.

It's serverless, so you're not paying when the POC isn't
being demoed."
```

### 3. Snowflake Comparison (she knows it)
```
"You've used Snowflake at Chewy and Acxiom. For enterprise
scale, Snowflake is solid. But for POCs, startups, and
workloads under 1TB—Snowflake is overkill.

MotherDuck is 70% cheaper, no idle costs, and honestly
faster for most queries because we're not coordinating
across distributed nodes."
```

### 4. GalleryAI Fit
```
"For GalleryAI, you're probably not at petabyte scale yet.
MotherDuck's free tier gives you 10GB storage and 10
compute hours—enough to build and test.

And because it's built on DuckDB, you can develop locally
on your laptop for free, then seamlessly query cloud data
when you need it. Same SQL, same experience."
```

### 5. Responsible AI / Governance (her values)
```
"You talk a lot about responsible AI and governance.
MotherDuck is SOC 2 Type II certified, HIPAA BAAs available.
For the enterprise clients you work with at IBM, we can
```
