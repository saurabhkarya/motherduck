***DuckDB has become incredibly popular in the ML and data science community***

**Why**
DS love DuckDB, you can run directly in Python/R and don't need a separate database server
Fast for the exploratory analysis and feature engineering that happens during model development
Works seamlessly with pandas, Arrow, Parquet
Fits into Jupyter and local workflows

**You can use MotherDuck, if you want to:**
Move from individual experimentation to collaboration
Datasets too large but keep duckDb exp
Shared datasets or feature stores
Productionizing ML pipelines that need cloud scale compute
